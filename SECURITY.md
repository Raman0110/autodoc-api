# Security policy

## Supported versions

Security fixes are provided for the latest published version of `autodoc-api`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
Raman Tamang at `ramantamang556@gmail.com` with:

- the affected version;
- a minimal reproduction or proof of concept;
- the potential impact; and
- any suggested mitigation, if known.

You should receive an acknowledgement within 72 hours. A status update will
follow within seven days. Please allow time for a fix and release before
public disclosure.

AutoDoc analyzes local source code and does not transmit it. The built-in
documentation pages load their selected renderer from jsDelivr; protect or
disable those pages in production when that does not match your security
policy.
